


# Recipes App

## Description
Recipes App is a Flutter application that displays a list of recipes with detailed information, built with MVVM architecture. It uses the DummyJSON API to fetch recipe data and features smooth animations, shimmer loading effects, and clean error handling.

## Tech Stack
- **Flutter** — UI framework
- **Dio** — HTTP client for API requests
- **Provider** — state management (MVVM)
- **Lottie** — loading animations
- **Shimmer** — skeleton loading effect
- **CachedNetworkImage** — efficient image loading
- **FlutterRatingBar** — rating display
